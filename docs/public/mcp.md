# MCP Roadmap

Version: unreleased
Last Updated: 2026-10-16
Canonical: /docs/mcp.md

## Availability

Sorrel does **not** currently ship an MCP server, Streamable HTTP endpoint,
MCP tools, or `sorrel://` resources. The supported interfaces in this repository
are the local Streamlit app and local CLI.

The MCP names and connection examples previously published here were design
proposals. They are not available to ChatGPT, Claude, Codex, or any other MCP
client.

## Future direction

An MCP integration will be announced only with an implemented server, explicit
authorization and data-isolation controls, and black-box conformance tests.
