How it differs

Checked results, not just fluent ones

A chat model can write fluent numbers that were never computed. DSA Agent computes with Python tools, compares the written summary against them, and says what it could not verify.

Chat LLMs and spreadsheets

Watch out
  • ✕ Invented arithmetic: a chat model can write plausible numbers that were never calculated from your rows.
  • ✕ Leakage between train and test: when training and test rows are mixed, accuracy looks far better than it will be on new data.
  • ✕ Unchecked methods: a spreadsheet applies whatever formula was typed, even when the test does not fit the data.
  • ✕ Hard to repeat: prompts can give a different answer on each try, so two sessions may not agree.

What DSA Agent does

Checks built in
  • ✓ Python does the math: calculations run as Python code (pandas, SciPy, scikit-learn), not as prompt arithmetic.
  • ✓ Overfitting checks: models are scored on held-out data, and a train-test gap above 0.10 raises a warning.
  • ✓ Raw rows stay out of prompts: only compact metadata and tool summaries go to the AI model, never the full table. Switch AI off and nothing is sent to a provider.
  • ✓ Repeatable by design: random steps use fixed seeds, and each run writes Markdown and JSON reports you can inspect.
