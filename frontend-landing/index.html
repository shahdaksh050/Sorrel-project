FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

Clear answers about architecture, security, and statistical methodology.

DSA Agent enforces an architectural wall between reasoning and execution. Large Language Models never perform mathematical calculations in prompt tokens. Instead, the model writes clean, audited Python code that runs inside a local REPL sandbox (Pandas, SciPy, Scikit-Learn), guaranteeing 100% verified arithmetic.
No. Raw data rows never leave your local machine or VPC. The controller only supplies high-level column metadata and statistical summaries (type, missingness, quantile bounds) to the reasoning engine, keeping your proprietary dataset completely air-gapped.
By default, all models are evaluated with 5-Fold Stratified Cross-Validation. The system continuously tracks the delta between train score and cross-validation score. If this generalization gap exceeds 10%, L2 regularization penalties are automatically raised and tree depths are clamped to prevent memorization.
DSA Agent supports CSV, TSV, Parquet, and Excel (.xlsx) files out of the box, with automatic delimiter inference, multi-encoding detection (UTF-8, Latin-1), and type casting.
RLM is an autonomous workflow architecture where complex, multi-variable analytical objectives are recursively decomposed into atomic execution steps. An external REPL memory environment tracks all intermediate variables, logs, and chart objects across all 7 stages.
